# 広告画像の画角そろえツール

画像のまわりに白い余白を足して、広告用のサイズにそろえるツールです。
画像の切り取り・引き伸ばし・縦横比の変更はしません。画像はいつも真ん中に置かれます。

画像はお使いの端末（パソコン・スマホ）の中だけで処理され、インターネットには送信されません。

## 使い方

1. 次のアドレスをパソコンの Chrome で開きます（ブックマークしておくと便利です）。
   https://rnakano-mui.github.io/ad-image-resizer/
   ※ `index.html` をダウンロードしてダブルクリックで開いても、同じように使えます。
2. 画像をドラッグして入れるか、「画像を選ぶ」から選びます。何枚でも一度に入れられます。
3. 作りたいサイズにチェックを入れます（最初は全部チェックされています）。
4. 必要なら「内側の余白」（0〜15%）と「保存形式」（JPG／PNG）を選びます。
5. 1枚ずつ「保存」するか、「まとめて保存（zip）」で全部まとめて保存します。

## 作れるサイズ

| 比率 | サイズ | 主な使い道 |
|---|---|---|
| 1:1 | 1080×1080 | Metaフィード・カルーセル／Googleスクエア |
| 4:5 | 1080×1350 | Metaフィード縦長／Google縦長 |
| 9:16 | 1080×1920 | Metaストーリーズ・リール／Google Demand Gen縦型 |
| 1.91:1 | 1200×628 | Metaリンク広告／Google横長 |

比率が同じ場合は、Meta のサイズに合わせています。

## 設定の意味

- **内側の余白**: 0% のときは、画像が枠いっぱいに入ります（余った部分だけ白くなります）。
  数字を上げると、四辺にさらに白い余白が入ります。余白の幅は、出来上がりの短い辺に対する割合です
  （例: 1080×1080 で 10% なら各辺 108px）。
- **保存形式**: 通常は JPG（品質 0.92）をおすすめします。PNG はファイルが大きくなりがちです。

## 画面に出るお知らせ

- **「拡大 ○倍」**: 元の画像を 1.05 倍より大きく引き伸ばしています。ぼやけることがあるので、
  できればもっと大きな元画像を使ってください。
- **「Googleに入稿できません」**: 出来上がったファイルが 5MB を超えています。JPG で保存してください。
- **「読み込めませんでした」**: HEIC（iPhone の写真形式）など、ブラウザが開けない画像です。
  JPG か PNG に変換してから入れてください。

## 保存されるファイル名

- 1枚ずつ: `{元のファイル名}_{幅}x{高さ}.{jpg または png}`（例: `商品A_1080x1080.jpg`）
- まとめて: `広告画角_YYYYMMDD.zip`（例: `広告画角_20261103.zip`）
- 同じ名前の画像を2枚入れた場合は、2枚目以降の名前の後ろに `_2` などが付きます。

## 管理する人向け

- 中身は `index.html` 1ファイルだけです（HTML・CSS・JavaScript をまとめて書いています）。ビルドは不要です。
- サイズを増やす・減らすときは、`index.html` の冒頭にある `SIZES` を書き換えます。
  `on: false` にすると、最初はチェックが外れた状態になります。
- 外部から読み込むのは、zip 作成用のライブラリ JSZip 3.10.1（cdnjs）だけです。
  インターネットにつながっていないときは zip 保存だけ使えず、1枚ずつの保存は使えます。
